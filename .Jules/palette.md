## 2026-06-01 - [Model Picker Search UX]
**Learning:** In highly interactive search inputs, users expect a way to clear the query with a single click. A small "X" button provides a convenient shortcut that is faster and more intuitive than manually backspacing or selecting all text.
**Action:** Always include a 'Clear' (X) button for search-style inputs. Ensure it is accessible by providing a clear `aria-label` and ensuring it can be focused and triggered via keyboard. Use a consistent SVG icon rather than a plain text character for better visual polish and cross-browser consistency.
